Bookmark folder → Label
Paste a bookmarks folder path (example: Bookmarks bar/Reading) or a folder ID/URL (example: 1118 or chrome://bookmarks/?id=1118) and a label. Clicking Add will save every bookmark URL in that folder to Omnivore with that label.
